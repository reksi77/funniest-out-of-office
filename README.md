A single out-of-office auto-reply line — 96 characters, one line, no clichés — written by a small TypeScript program that prints exactly that line to `/output/entry.txt`. The joke: the auto-reply is the only employee still working, and it has already asked for a raise.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
